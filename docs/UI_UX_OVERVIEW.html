P1 Make discovery task-oriented

Add homepage shortcuts and category filters. Reduce directory card height; remove serial codes such as ENC-01. Fix both directory-return links, which currently lead home, and replace the inactive Request a Tool action.

P1 Standardize feedback, touch, and keyboard behavior

Give upload rejection and processing failures useful recovery actions. Name controls, label sliders, announce status, and provide visible focus. Watermark positioning needs pointer and keyboard support. Make mobile export bars reflect the current state.

P0 / P1 Make trust language precise

“Without telemetry” conflicts with mounted analytics. “Zero latency,” unlimited capacity, and blanket offline readiness overpromise. Say images are processed on-device, disclose analytics accurately, and show offline readiness only after verification.
